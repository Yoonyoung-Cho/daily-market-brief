# 리포팅 (reporting)

## 목적
`data/pair_analysis.json` 을 사용자에게 전달한다: 추천 목록(테이블)에서 쌍을
선택하면 상세 분석 화면(차트·해석)으로 이동.

## 화면 구성
1. **헤더**: MARKET/UNIVERSE/기간/윈도우 + 디스클레이머(필수).
2. **추천 테이블**: 쌍, 관계유형, 출처(시드/통계), 괴리지표, 현재값,
   z-score, 백분위, 반감기, 스코어. 스코어 내림차순.
3. **상세 화면** (선택 시):
   - 지표 카드: 현재 괴리값 / z-score / 백분위 / 반감기.
   - 경제적 해석 문장.
   - 차트 3종: 정규화 가격, 괴리지표+±1σ/±2σ 밴드, z-score 추이.

## 규칙
- **모든 화면 상·하단에 "투자 자문 아님" 디스클레이머**를 표시한다.
- 표시 단위: 할인율/디스카운트는 %, 스프레드는 소수.
- 차트는 `src/viz/charts.py` 의 순수 함수 사용.
- 무거운 연산(파이프라인)은 버튼 트리거 + 캐시; 화면 로드는 JSON 읽기만.

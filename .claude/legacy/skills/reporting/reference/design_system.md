# 리포트 디자인 시스템

자기완결형(self-contained) 정적 HTML. 외부 폰트/CDN 의존 없이, Plotly 는 인라인.
주식 비전문가가 위에서 아래로 읽으며 이해하도록 정보 위계를 설계한다.

## 색 / 토큰
- 배경 `#0f1420`(딥네이비) · 카드 `#1a2030` · 텍스트 `#e8edf6` · 보조 `#9aa7bd`
- 강조(브랜드) `#5b9dff` · 경고/벌어짐 `#ff6b6b` · 안정/좁혀짐 `#4dd4ac`
- 시스템 폰트 스택만 사용(외부 폰트 로드 금지).

## 레이아웃 (위→아래)
1. **헤더**: 제목 · 시장/통화 · 데이터 출처 · 생성시각 · 디스클레이머 배너.
2. **"이게 뭔가요?" 교육 박스**: 페어/괴리율 비유, 파이프라인 5단계, 핵심용어 카드.
3. **추천 카드 그리드**(스코어순): 종목명 · 관계유형 배지 · 왜 비교하나 · 스코어바.
4. **상세**(카드 펼침/단일): 지표 4종 + 분석가 해석(headline/what/why/caveat) +
   차트 4종(실제가격·정규화·괴리밴드·z-score).
5. **푸터**: 데이터 출처 재명시 · 디스클레이머.

## 카피 규칙
- 모든 전문용어 옆에 한 줄 평이한 설명 또는 `?` 툴팁.
- z-score/백분위/반감기는 "평소 대비 얼마나 드문지/얼마나 빨리 되돌아오는지"로 번역.
- 통화: KR=`70,000원`(접미), US=`$123.45`(접두).

## 금지
- 차트 정크(불필요한 3D·그림자·과한 애니메이션). 장식이 데이터를 가리면 안 됨.
- 투자 권유 표현. 외부 리소스 요청(폰트/이미지 CDN).

# 공적분 검정 레퍼런스

## 1. 상관 (1차 필터)
로그수익률 `r_t = log(P_t) − log(P_{t-1})` 의 Pearson 상관.
- 동조화 후보를 빠르게 좁히는 용도. **단독 추천 근거로 쓰지 않는다.**
- 추세장에서는 비공적분 쌍도 높은 상관을 보일 수 있음(가짜 신호).

## 2. Engle-Granger 2단계 공적분 (핵심 필터)
1. `statsmodels.tsa.stattools.coint(logA, logB)` → coint p-value.
2. 회귀 `logA = α + β·logB + ε` (OLS) 로 β, α 추정.
3. 잔차 `ε` 에 ADF 검정(`adfuller`) → ADF p-value.
4. **coint p ≤ 임계 AND ADF p ≤ 임계** 이면 공적분 성립으로 본다(기본 0.05).

해석: 두 로그가격이 장기 균형관계(`logA − β·logB` 가 정상)를 가진다는 뜻.
이때 스프레드 `ε` 가 평균회귀하므로 괴리율 분석이 의미를 가진다.

## 3. 엣지 케이스
- 관측치 < 30: 검정 불안정 → p=1.0 으로 처리해 배제.
- 공통 거래일 부족: `min_overlap_days` 로 사전 컷.
- β 부호/크기: 음수 β 는 역방향 관계. 스프레드 정의는 동일하게 적용.
- 다중공선성·계절성은 일별 주가에서는 통상 무시.

## 4. 확장 (선택)
- Johansen 검정: 3종목 이상 다변량 공적분(향후 바스켓 확장 대비).
- 시간가변 β: Kalman filter / rolling OLS (룩어헤드 주의).

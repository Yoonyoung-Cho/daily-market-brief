# 분석가 해석 작성 (equity-narrative)

## 목표
숫자를 "그래서 이게 무슨 뜻인지"로 바꾼다. 주식을 모르는 사람이 읽어도
무엇이 벌어졌고, 왜 두 종목을 함께 보며, 무엇을 조심해야 하는지 알게 한다.

## 4요소 (dict 반환)
- `headline` : 한 줄 결론. 예) "평소보다 가격차가 크게 벌어진 상태(최근 2년 상위 3%)".
- `what`     : z-score/백분위를 일상어로. |z|≥2 → "매우 드문 수준",
  1~2 → "다소 벗어남", <1 → "평소 범위". 백분위는 "최근 2년 중 ○○번째로…"로.
- `why`      : 관계유형별 한 문단.
  - pref_common  → "같은 회사의 보통주와 우선주라 본질가치를 공유, 차이는 보통 일정"
  - holdco_sub   → "지주사와 자회사는 지분으로 묶여 자회사 가치가 지주사에 반영"
  - group_chain  → "공급망/그룹으로 사업이 맞물려 같은 사이클"
  - industry_peer→ "같은 산업이라 업황을 공유"
  - statistical  → "경제적 이유는 단정 못 하지만 통계적으로 강하게 동조(공적분 통과)"
- `caveat`   : 반감기("평균회귀 반감기 ≈ N일 = 과거엔 평균으로 돌아오는 데 통상 N일"),
  구조 변화 가능성(합병·정책), "이는 매매 신호가 아니다".

## 어조 규칙
- 예측·단정 금지("오른다/내린다" X). "통계적으로 ~한 상태" 까지만.
- 전문용어 옆 괄호 설명 필수. 숫자엔 단위/통화.
- 표본 부족(z=NaN) 시 솔직히 "데이터가 짧아 판단 보류".

# 지주사 NAV 디스카운트 (holdco_sub)

## 개념
지주사의 시가총액은 보유 자회사 지분가치의 합(NAV)보다 **낮게** 거래되는 경향이
있다(더블카운팅·세금·할인). 이 차이가 NAV 디스카운트.

## 측정 (단순화: 단일 자회사 기준)
    보유지분가치 = 자회사 시가총액 × 지분율(stake_pct)
    NAV          = 보유지분가치 − 순부채(net_debt)
    NAV 디스카운트 = 1 − (지주사 시가총액 / NAV)
- 실제 지주사는 여러 자회사를 보유 → 본 시스템은 시드의 대표 자회사로 근사.
- 정밀 분석에는 전 자회사 지분가치 + 비상장가치 + 순현금을 합산해야 함.

## 입력값 갱신
- `stake_pct`, `net_debt` 는 **최신 분기보고서/공시** 기준으로 채운다.
- 지분 매각·증자·합병 시 즉시 갱신하거나 시드에서 제외.

## 평소 vs 현재
- 시가총액 시계열(KR: pykrx `시가총액`)로 디스카운트 시계열 구성.
- 롤링 z-score·백분위로 "디스카운트가 평소보다 깊은가/얕은가" 표현.

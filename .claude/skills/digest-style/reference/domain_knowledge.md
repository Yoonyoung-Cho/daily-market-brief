# 시장 도메인 지식 (브리핑·검증 공통 필수)

market-research-analyst 와 research-verifier 가 **반드시 숙지**할 한국 주식시장 기본기.
해석/검증은 이 지식에 어긋나면 안 된다.

## 1. 지수 메커니즘 (가장 흔한 오류원)
- **KOSPI·KOSDAQ 는 시가총액 가중 지수.** 지수 등락 기여도 ≈ (종목 시총 비중) × (등락률).
- **"지수 하락/상승을 주도했다"는 시총 기여도로 판단한다.** 시총 1,900조 삼성전자가 -7%면
  시총 1조 종목이 -25% 빠진 것보다 지수를 압도적으로 더 움직인다.
- **% 등락 상위(상·하한가 등) ≠ 지수 주도.** 대부분 중소형주라 지수 영향은 미미.
  → 데이터의 `index_drivers`(등락%×시총)를 근거로 대형주를 지목할 것.
- 코스피 대장: 삼성전자·SK하이닉스(반도체)가 시총 1·2위로 지수를 좌우.

## 2. 데이터 시점·정합성
- 본 시스템 시세는 **일별 종가(close) 기준**, 등락률은 전일 종가 대비. 장중 실시간 아님.
- 상·하한가 ±30%. 거래정지·이상치는 신호에서 제외.
- 룩어헤드 금지: 과거 시점 신호는 그 시점 이전 데이터만 사용.

## 3. 종목 구조 (페어/지주)
- 보통주-우선주: 같은 회사, 우선주는 의결권 없고 보통 할인 거래.
- 지주사-자회사: 지주사는 자회사 지분가치(NAV) 대비 할인(디스카운트) 거래.

## 4. 섹터 지식 (대표 종목 — 종목·섹터 매칭 검증용)
- 반도체: 삼성전자·SK하이닉스·한미반도체·이오테크닉스·DB하이텍
- 2차전지: LG에너지솔루션·삼성SDI·에코프로비엠·포스코퓨처엠
- 방산·우주: 한화에어로스페이스·LIG넥스원·현대로템·한화시스템·한국항공우주
- 조선: HD현대중공업·한화오션·삼성중공업·HD한국조선해양
- 자동차: 현대차·기아·현대모비스
- 플랫폼: NAVER·카카오 / 금융지주: KB금융·신한지주·하나금융지주
- 원전·전력: 한국전력·효성중공업·LS ELECTRIC / 바이오: 삼성바이오로직스·셀트리온

## 5. 밸류에이션 상식
- PER(주가/주당순이익): 낮다고 무조건 싼 것 아님(역성장·리스크 반영일 수 있음).
- 방산 등 성장 기대 섹터는 고PER 정당화 논리가 있으나 그만큼 기대 선반영 → 변동성 큼.
- 컨센서스 '목표가 상향'은 긍정 신호지만, 다수 상향은 이미 주가에 반영됐을 수 있음.

## 6. 반드시 피해야 할 해석 오류 (체크리스트)
1. **% 등락 ≠ 지수 기여** (시총 가중 무시) ← 최우선 점검.
2. 상관 ≠ 인과. "같이 움직였다"가 "원인"은 아니다.
3. 하루 등락으로 추세·방향 단정 금지.
4. 거래정지/액면분할/배당락발 가격 점프를 실제 변동으로 오인.
5. 종목-섹터 오분류(예: 보안주를 반도체로).
6. 출처 없는 수치·날짜 불명 자료를 '오늘 동향'으로 둔갑.
